## 项目：Free Mind Map 开源思维导图软件
- 目标：基于 Electron 的开源思维导图，文件为纯文本 `.mdm`（JSON），图片外置于同目录 `.swdt`。
- GitHub：https://github.com/hupingin/free_mind_map （远程已添加，初始 commit 已建，未 push）
- 技术栈：Electron + 原生 JS/SVG（无框架、无打包步骤即可跑）。contextIsolation + preload 桥接文件 API。
- 已实现：6 种结构布局（mindmap/logical/tree/org/fishbone/timeline）、SVG 渲染、内联编辑、右键菜单、主题(换肤/彩虹/手绘)、大纲互转、搜索、演示、导出 PNG/SVG/MD/PDF。
- 架构要点：内存中图片为 data URI，保存时由 main.js externalizeImages 写入 .swdt 并替换为文件名；打开时 internalizeImages 读回。
- Roadmap（未做）：AI 生成、实时协作、甘特图/任务进度、多端云同步、安全分享。
- 验证：所有 JS 通过 `node --check`；新增 `test/render-smoke.js`（纯 Node + 最小 SVG DOM 垫片）经 `npm test` 跑通——6 种结构布局无 NaN、draw() 生成节点、getSVGString() 输出 4070 字符合法 SVG、序列化往返一致。`npm test` exit=0。
- 依赖：用户本机 `npm install` 已完成，electron 二进制就位（dist/electron.exe v20.16.0，449MB）。沙箱内 `ELECTRON_RUN_AS_NODE=1` 被强制、且无显示器，故 Electron GUI（app 模式）无法在此实机启动——真机执行 `npm start` 即可。
- 新增 `npm test` 脚本；package.json 未改动 electron 版本范围（^30.5.1，本地二进制为 20.16.0，API 兼容）。
